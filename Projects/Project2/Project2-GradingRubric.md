# Project 2: Improve Your Code 

## Grading Rubric

### The Draft Version

The __draft version__ will simply need to have something for each section below. A *completely missing section* will be scored as zero points. Each section will be worth 10 points. Your project will not need to pass the reproducibility test, although it is highly recommended. 

The instructor will provide feedback on each section that needs improvement. 


### The Final Version

The __final version__ of Project 2 will be scored on the presence, organization, and completeness of each of the project items outlined below.

#### Reproducibility Test

Successful replication of the Project by the instructor. The replication process is as follows: 
    1. The zip file is downloaded and uncompressed. 
    2. The RStudio project is opened using the RProj file. 
    3. The RMD is opened and ``Knit" button is pressed.

If the RMD fails to knit, or if there are errors produced in the code, the project will receive no more than 50% of the available points.

#### File Components (10 points)

All required files are present: RMD, data set, README, Rproj file, and saved visualization(s). 

Rubric:

 - Full points: All files are present.
 - -4 points for each missing file.
 - No points: More than two required files are missing.

#### Organization (20 points)

Files are organized according to the standard organization discussed in the Best Practices handout. 

Rubric:

  - Full points: All files are organized appropriately. 
  - -5 points for each file misplaced.
  - No points: no folders organizing files in the project.


#### Documentation (20 points)

Documentation includes the README file and notes in the code that explains how it functions. Additionally, required elements of documentation of Project 1 are also included here (File header, Setup, Loading and cleaning, References.)

Rubric:

  - Full points: Both the README and internal code documentation is present and sufficient. 
  - -10 points: no reference to original data set.
  - -5 points: each insufficient description in the Project 1-assessed RMD file components.
  - 10 points: either the README or internal code documentation is missing or insufficient.
  - No points: Neither README nor internal code documentation are present or sufficient.


#### Coding Requirements (30 points)

The code producing your visualization should include at least __three elements from at least two categories__ the following list: 

  - a function created by you that is used at least twice;
  - a loop; and/or
  - a conditional statement.
    
These elements need to exist in non-trivial way that adds to the complexity of the project. 
    
Rubric: 

 - Full points: contains all elements as described.
 - -10 points: each missing element or each element present but not meaningfully adding to the code.
 - No points: No elements present.


#### Visualization (20 points)

One or two visualizations that meeting basic accessibility and readability requirements. Text should describe the figure and interpret the figure for the viewer/reader. Any feedback from the instructor from the draft version should be addressed.

Rubric: 

  - Full points: one or two visualizations are present and adequate. 
  - -5 points: for too many visualizations (more than two).
  - -10 points: absent or inadequate text descriptions. 
  - -5 points: not addressing feedback from instructor.
  - No points: no or inadequate visualization(s).


#### Generative AI Reflection (Optional)

If you have used GenAI in creating your project, you must include a reflection (text only) which covers the following: which GenAI resource was used (Chat GPT, CoPilot, etc), how the resource was used to produce the code and how that code was integrated into your project, and any complications you experienced using the resource. 

Rubric: 

  - Full points: Gen AI was used and the reflection is present and complete. 
  - 25% deduction: Gen AI was used and the reflection is absent.
